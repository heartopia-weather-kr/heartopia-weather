# 특별 리딤코드 수동 등록 (모바일 GitHub)

자동 수집은 `redeem-codes.json`만 수정합니다. 특별 코드는 이 파일이 아닌 `manual-redeem-codes.json`에 등록하세요.

1. GitHub에 로그인한 뒤 저장소의 `manual-redeem-codes.json` 파일을 엽니다.
2. 연필(Edit) 버튼을 눌러 `codes` 배열에 새 객체를 추가합니다. 기존 항목 사이에는 쉼표가 필요합니다.
3. `code`는 영문/숫자/밑줄/하이픈 5~40자, `rewards`는 쉼표로 구분한 보상 문자열입니다.
4. `expiresAt`은 UTC ISO 8601 형식입니다. 예: 한국시간 2027-01-01 00:59 = `2026-12-31T15:59:00Z`. 만료일을 모르면 `null`로 둘 수 있습니다.
5. `source`에는 공식 게시물 URL을 권장하며 `postedAt`은 확인 가능한 게시 시각(UTC ISO 8601), 모르면 `null`로 둡니다. `type`은 `"special"`로 유지합니다.
6. **Commit changes**를 눌러 기본 브랜치에 저장하면 GitHub Pages 배포 후 별도 승인 없이 공개됩니다. 실제 반영까지 배포/캐시 지연이 있을 수 있습니다.

중복 규칙: 코드 앞뒤 공백과 영문 대소문자를 무시하고 같은 코드로 간주합니다. 자동/수동 파일에 동시에 있으면 수동 등록 객체를 우선하며 목록에는 한 번만 표시됩니다. 수동 파일 자체에 중복을 만들지 마세요. 유효하지 않은 개별 코드는 화면에서 제외될 수 있습니다.

스크린샷으로 등록할 때도 코드·보상·만료일·공식 출처를 먼저 확인한 뒤 이 파일에 추가합니다. 실제 게임 사용 가능 여부는 별도로 확인해야 합니다.
