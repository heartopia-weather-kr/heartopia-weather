## 보류 1 — 리딤코드 사이트 표시 UI
- **상태:** 보류. 사용자가 나중에 진행하기로 결정함.
- **이미 존재하는 부분:** `redeem_collector.py` 및 `redeem-codes.json` 관련 수집·데이터 흐름. 이전 검토에서 수집기는 Discord 집계 채널 하나를 읽는 구조로 확인됨. 원본 채널에서 집계 채널로 전달하는 설정은 별도.
- **디자인 방향으로 논의한 내용:** 화려하지 않은 **쿠폰 모양 아이콘 + '리딤코드'** 진입점, 선택 시 코드 목록을 세로로 보여주기, 만료된 코드 구분.
- **미확정:** 최종 PC·모바일 상세 배치, 펼침/팝업 방식, 만료 분류의 정확한 UI, 코드 복사·보상 표시 등 상세 동작. 이전 시안은 최종 승인 디자인으로 간주하지 않음.
- **재개 조건:** 사용자가 리딤코드 UI 작업을 명시적으로 요청할 때. 그때 기존 수집 데이터와 현재 사이트 디자인을 대조해 확정.
- **금지:** 보류 상태에서 임의 구현·배포하거나 이미 확정된 기능으로 표시하지 않기.
